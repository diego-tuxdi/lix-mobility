# Reglas para IA

No modificar títulos sin autorización.

No agregar slogans nuevos.

No generar textos comerciales alternativos.

No utilizar clichés como:

- El futuro de...
- Revolucionamos...
- Cambiamos la industria...
- La mejor plataforma...
- Experiencia única...
- Innovación sin límites...

El tono debe sentirse cercano, tecnológico y honesto.

El producto debe transmitir confianza mediante claridad, no mediante promesas exageradas.
